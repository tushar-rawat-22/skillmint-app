# SkillMint support

SkillMint is a controlled beta. Public GitHub issues are appropriate for reproducible product bugs, accessibility problems and non-sensitive product feedback.

For account access, privacy questions, personal-data concerns, or anything involving private user material, use `skillmint.operations@gmail.com` instead of a public issue.

For security vulnerabilities, follow `SECURITY.md`.

When reporting a public bug, include the workflow, expected result, actual result, browser/device details when relevant, and the smallest reproduction you can provide. Do not include names, email addresses, resume text, job-description text, passwords, authentication details, or private screenshots. Use synthetic examples instead.

SkillMint does not currently offer a guaranteed support-response SLA. Controlled-beta support is handled manually while the first user cohort is being evaluated.
